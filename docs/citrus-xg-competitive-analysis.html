Where We Rank — Visual Benchmarks
Our metrics plotted against industry-standard benchmarks for NHL xG models

AUC-ROC Comparison

Higher = Better
AUC-ROC: Area Under the Receiver Operating Characteristic Curve. 0.50 = coin flip, 1.0 = perfect. Industry-standard xG models range from 0.72 to 0.80.

Brier Score

Lower = Better
Brier Score measures the mean squared error of probabilistic predictions. For NHL data (~8% base rate), a "perfect" naive model scores ~0.074. Anything below 0.065 is excellent.

Feature Count

More Context
More features = more context per shot. Our 31 features capture shot location, game state, strength situation, passing sequences, rebounds, and arena adjustments.
