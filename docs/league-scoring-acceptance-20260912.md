## Common contract

[Shared scoring](../packages/shared/src/utils/scoring.ts) owns earned-points calculation; the historical [web import](../apps/web/src/utils/scoringUtils.ts) re-exports it. [League projection helpers](../packages/shared/src/leagueProjection/index.ts) normalize configured rules, require enabled forecast components, and rescore raw counts. A conditional goalie row is weighted by its explicit start exposure once; an unconditional row is not weighted again. Rates such as save percentage remain rates. Real zero and negative points remain valid; unsupported or missing inputs remain unavailable.

An explicitly loaded league row with persisted `scoring_settings: null` means the configured defaults. A missing field, failed read, wrong league, or not-yet-loaded league does **not**. [useLeagueScoringContext](../apps/web/src/hooks/useLeagueScoringContext.ts) gates readiness, guards late responses, reacts to changed context settings, and refreshes on a 120-second interval and focus. A matching context seed avoids an initial cache overwrite; focus refresh is suppressed for its first 30 seconds to avoid the older league-service cache. Default preview behavior requires an explicit preview option. These are bounded refresh policies, not instantaneous remote-update guarantees.

## Published-source consistency

[CanonicalProjectionService](../server/src/services/CanonicalProjectionService.ts) reads active published views, pages exact player IDs, and rejects mixed revisions. [PlayerDashboardService](../server/src/services/PlayerDashboardService.ts) invalidates its base cache when the run, revision, or calculation refresh timestamp changes. Forecasts require matching ROS run/revision stamps and projected status. It checks publication before and after hydration, retries a changed publication once, then withholds forecasts if consistency cannot be established. A lookup error is distinct from a successful “no active run” result: it preserves actual stats and withholds forecasts/context, rather than falling back to unstamped legacy forecasts. [Canonical service tests](../server/src/__tests__/CanonicalProjectionService.test.ts) cover pagination, revision races, stamp mismatches, calculation-epoch refresh and failure behavior.

- No network/device draft-night latency or sustained live-load benchmark is claimed here. Unit tests and mock API timing are not those measurements.
