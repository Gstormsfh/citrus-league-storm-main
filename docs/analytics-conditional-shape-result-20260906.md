## What changed

The movement raw predictor, original features and corrected movement vectors
were held fixed. Only the calibration map changed: nonnegative probability-shape
slopes can differ by prior-same-team-SOG context, partially pooled toward shared
slopes. Missing context is separate from false. The pooling penalty was fixed
before fitting; no hyperparameter sweep or fallback winner selection occurred.
Training, earlier calibration and validation membership stayed unchanged.

The source replay matched every saved movement feature vector and all frozen
validation raw/mapped predictions exactly. Only earlier calibration labels fit
the new map. JSON-roundtripped predictions were checked against independent
scalar arithmetic for every calibration and validation row within 1e-12.
