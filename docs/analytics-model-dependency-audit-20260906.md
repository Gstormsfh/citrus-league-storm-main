## Extraction-path parity gap

`process_game_from_raw_data` (`data_acquisition.py:2179`) computes xG, nonpublishing sequence shadow, xA and flurry before calling the common save helper (`:2327`). `process_single_game` (`:2333`) additionally computes rebound probability, expected rebound goals, talent-adjusted xG and created xG (`:3864`–`:4018`). The common save helper supplies defaults for absent columns (`:1893`–`:1899`). Consequently, a populated output column does not prove that its original model ran. Before any promotion, replay the **same** payload through both authorized paths and compare computed/unknown status as well as values. This audit did not execute either acquisition module because importing it loads legacy binaries.

## Reproduced legacy rebound-index defect

`identify_saves_and_rebounds` groups by game/period, sorts and resets the group index (`calculate_goalie_rebound_control.py:170`), then writes results to the full dataframe using that reset index (`:191`). A synthetic two-game example puts the only rebound in the second game, yet the function marks a row in the first game. This is a deterministic row-identity defect, not an uncertain statistical diagnosis. It was reproduced by AST-extracting only the pure function, without executing module imports or database code. The standalone proof is `scripts/proof/reproduce_legacy_rebound_index.py`.

This finding does **not** establish that current scheduled SQL GSAx or the base shot model is affected. The gate is to establish whether the utility is invoked, then fix and replay its own population without overwriting old evidence.

## Practical order

1. Complete original extraction/feature/artifact parity before describing a challenger as a successor.
2. Test original lateral/timing/rebound signals and their missing-state handling on identical source events, then compare frozen out-of-time candidates.
3. Validate each distinct continuation/creation/talent/goalie quantity and preserve lineage; do not cascade a base-score change through silent fallbacks.
4. Reconcile on-ice aggregates and physical forecasts before GAR/FPAR acceptance. Keep raw actuals and old scored evidence immutable.

Remaining scope: artifact training provenance, actual scheduler/database runtime inventory, full workflow replay, xA observed-label validation, rebound continuation calibration, and cross-consumer promotion are not completed by this read-only audit.

### Independent movement arithmetic review

The pair module preserves signed lateral crossing, physical distances and rates, orientation-rotation invariance, shortest angular displacement behind the net, unknown rates for same-clock events, and undefined angle at goal center. The original review found finite-input rate overflow for a subnormal elapsed time and a huge-integer validation exception; the parent implementation added fail-closed guards, and the independent tests now pass. The extra tests also cover coordinate extremes, same-location true zeros, preservation of geometry when time is unknown, long-clock clipping only of the legacy comparator, and input/result independence.

This does not establish that legacy training bytes, legacy runtime extraction and a new model now agree. The module's documented boundary is arithmetic on an already eligible pair; upstream caller eligibility and fitted-model integration remain open. Source-pinned coverage tracking should retain an explicit open row for every input/family until its applicable gates are satisfied.
