Why Student-t Copula? (The Math That Matters)
A Gaussian copula has zero tail dependence — it assumes extreme events are independent. That means McDavid and Draisaitl both having monster 5-point games simultaneously is treated as essentially impossible. This is wrong.

Our Student-t copula with ν=5 has ~18% probability of extreme co-movement. When one linemate explodes, the other likely does too — because they share the ice. We mine this from real shift overlap data, assist chain frequencies, and empirical fantasy point co-movement.

This is the same mathematical framework used by quantitative trading desks for portfolio risk modeling. No fantasy platform does this.
# Student-t Copula Generation (the core math)
L = np.linalg.cholesky(corr_matrix)   # Cholesky decomp of correlation matrix
Z = rng.standard_normal((n_sims, d))    # d = number of players
X = Z @ L.T                                 # Correlated normals
S = rng.chisquare(5, n_sims) / 5        # Chi-squared / nu (tail weight)
T = X / np.sqrt(S[:, None])              # Student-t transformation
U = stats.t.cdf(T, 5)                    # Uniform marginals [0, 1]

# Antithetic Variates (halve the variance for free)
U_anti = 1.0 - U                       # Mirror image of each sample
U_combined = np.vstack([U, U_anti])   # 2x samples, lower variance

Sauce #5 — The Correlation Intelligence
ρ

Data-Driven Player Correlations

3 independent correlation sources mined from real NHL data • Replaces static heuristics
Data-Mined
Shift Overlap Mining
Queries player_shifts_official for actual ice-time overlap between any two players. Converts overlap fraction to correlation:

ρ = 0.10 + 0.55 × overlap_fraction, capped at 0.65.

0% overlap → ρ=0.10, 50% overlap → ρ=0.375, 80%+ overlap → ρ=0.60. This captures linemate effects: McDavid and Draisaitl share ~75% of even-strength ice time.
Primary Source
Assist Chain Mining
Counts passer-to-shooter connections in raw_shots table. Each assist connection adds correlation:

boost = min(0.20, total_connections × 0.008)

Additive on top of shift overlap. 15 assist connections → +0.12 additional correlation. Captures direct offensive chemistry (e.g., Fox to Panarin, Makar to MacKinnon).
Additive Boost
Fantasy Point Co-Movement
Computes Kendall’s τ from game-by-game fantasy point totals in shared games. Converted to Pearson:

ρ = sin(π/2 × τ)

Requires 5+ shared games and p < 0.10 significance. Captures emergent correlations that shift data alone might miss (e.g., goalie-defense synergies).

Sauce #6 — The Engineering
VR

Variance Reduction & Performance Engineering

Efficiency
Antithetic Variates
For every uniform sample U, generate mirror 1−U. Doubles effective sample size with zero computational overhead. Reduces CI width on win probability by ~30%.
2× Efficiency
Stratified Sampling
Allocate more simulations to game-count tiers with higher variance. Players with 4 games get proportionally more samples than 2-game players. Reduces overall estimation error.
Variance Aware
Vectorized Scoring
Fantasy points computed via NumPy matrix multiplication: stat_matrix @ weight_vector. 10× faster than Python loops. Processes 10K sims × 15 players in milliseconds.
10× Speed
Reproducible Seeds
Optional fixed seed parameter for deterministic results. Critical for debugging, A/B testing model changes, and validating that code changes don’t affect statistical output.
Deterministic
