Bayesian Shrinkage — Trust vs Sample Size

Core Formula
Projected_Stat = (W × Player_History) + ((1 - W) × League_Average)

// Weight (W) increases with games played:
if GP < 10:   W = 0.20   // 20% trust in player data
if 10 ≤ GP < 30: W = 0.20 + (GP - 10) × 0.035   // linear ramp
if GP ≥ 30:  W = 0.90   // 90% trust in player data

Skater Projection — Complete Formula

Per Game
// Final projection for each stat category:
Projected_Goals = Base_Goals × Finishing_Multiplier × DDR × B2B_Penalty × Home_Away

// Where:
Base_Goals = (Total_xG / GP) × Bayesian_Shrinkage
Finishing_Multiplier = clamp(Actual_Goals / xG, 0.7, 1.5)
DDR = clamp(Team_Def × Goalie × Offense, 0.7, 1.3)
B2B_Penalty = 0.95 if back-to-back, else 1.0
Home_Away = 1.05 if home, else 1.0

Finishing Talent

Raw = Goals / xG
Stab = min(Shots/50, 1.0)
Final = Raw×Stab + 1.0×(1-Stab)
// Capped [0.7, 1.5]
Floor: 0.7x   Ceiling: 1.5x

Defensive Difficulty (DDR)

DDR = Team_Def × Goalie × Off

Team_Def = Opp_xGA/60 / Lg_Avg
Goalie = Lg_SV% / Opp_SV%
Off = Opp_SF/60 / Lg_Avg
// Capped [0.7, 1.3]
Floor: 0.7x   Ceiling: 1.3x

GAR — Goals Above Replacement
Composite value metric • 5 components • Bayesian-stabilized per component

Skater GAR Components & Stabilization

5 Components
GAR = EVO + EVD + PPO + PPD + Penalties

// Each component is Bayesian-regressed:
Regressed_Rate = (TOI / (TOI + C)) × Raw_Rate + (C / (TOI + C)) × Replacement_Level

// Replacement Level = 75th percentile of position-specific rates
Component Full Name Stabilization (C) What It Measures Key Inputs
EVO Even Strength Offense 500 min TOI Offensive contribution at 5v5 xG, xA, shot generation
EVD Even Strength Defense 500 min TOI Defensive impact at 5v5 xGA suppression, shot blocking
PPO Power Play Offense 100 min TOI Offensive output on PP PP xG, PP xA, PP TOI
PPD Penalty Kill Defense 100 min TOI Defensive impact on PK SH xGA suppression, SH TOI
PEN Penalties 1000 min TOI Penalty taking vs drawing Penalties taken, penalties drawn

Goalie Win & Shutout Probability

Multi-Factor
// Win Probability
Win_Prob = Team_Goal_Diff × 0.15 + 0.50
if B2B: Win_Prob ×= 0.85
if Opp finish ratio > 1.1: ×= 0.95
