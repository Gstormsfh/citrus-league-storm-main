03Methodology

How the audit works and what is sourced vs. synthesized.
Replicated competitor methodology. Yahoo BLITZ is described as “statistical regression and machine learning” on recent stats [2]. ESPN exposes rolling-average projections with integer matchup ratings [1]. We implemented both approaches in code — no extra model layers added, no advantages handicapped. The Citrus side runs the shipped pipeline (xG v3 + Bayesian shrinkage + DDR + MC) [4].

Synthetic ground truth. Player-game outcomes are generated from per-archetype NHL distributions calibrated to 2024-25 averages (G/GP, A/GP, SOG/GP, etc.), with realistic Poisson sampling, opponent strength noise, and home/B2B effects. Seed-controlled (42) so all three systems are measured on the identical test data.

Reproduce in two commands.
# §01 — Single-game projection accuracy
$ python data-pipeline/monitoring/baseline_competitor_audit.py --n 10000 --seed 42

# §02 — Weekly win-probability calibration
$ python data-pipeline/monitoring/matchup_winprob_audit.py --n 1000 --seed 42
JSON outputs committed at docs/audit-results/single_game_accuracy.json and docs/audit-results/matchup_winprob_calibration.json.
