## Your steps, in order

**1. Install + first build (~30 min if Android Studio is already installed)**
```powershell
cd C:\Users\garre\Documents\citrus-league-storm-phase45
npm install                # picks up @capacitor/android
npm run build --workspace=apps/web
cd apps\web
npx cap sync android       # copies dist + plugin config into android/
npx cap open android       # opens Android Studio
```
In Android Studio: let Gradle sync, then Run on an emulator/device to smoke-test (sign-in round trip via the citrussports:// callback is the key thing to try).

**2. Push notifications (FCM) — optional for v1, required for parity**
Firebase console → your project (or create one) → Add Android app with package `com.citrussports.app` → download `google-services.json` → drop it at `apps/web/android/app/google-services.json`. The build works WITHOUT it (the gradle template guards it); push registration just won't function until it's there.

**3. Release signing (one-time, keep the keystore FOREVER)**
```powershell
keytool -genkey -v -keystore citrus-release.keystore -alias citrus -keyalg RSA -keysize 2048 -validity 10000
```
Keep `citrus-release.keystore` + passwords OUT of the repo (password manager + backup). In Android Studio: Build → Generate Signed App Bundle (AAB) with that keystore. Recommended: enroll in Play App Signing when uploading (Google holds the final key, yours becomes the upload key).

**4. Play Console listing**
- App name, short/long description, screenshots (phone + 7"/10" tablet), 512px icon, feature graphic
- **Data safety form** — you collect: email (account), user IDs, app interactions; encrypted in transit; **account deletion**: Play requires a way to request deletion INCLUDING a web link — the in-app flow exists (Profile → Delete Account); add a small page on citrusfantasysports.com describing deletion (or pointing at the in-app flow + a support email) and use that URL in the form
- Content rating questionnaire (fantasy sports, no real-money wagering → straightforward)
- Category: Sports; Contains ads: No

**5. THE GATE — which developer account type do you have?**
- **Organization account** (registered with D-U-N-S): no closed-testing requirement — you can go to production after review (review typically 1–7 days for new apps).
- **Personal account created after Nov 13, 2023**: Google requires a **closed test with at least 12 testers opted-in for 14 consecutive days** before you can apply for production. That's a hard 2+ week floor. If that's your situation: start the closed test NOW (league mates = testers) while iOS launches, and consider whether upgrading to an org account (needs a D-U-N-S number for Citrus) is faster/cleaner for a company anyway.

**Sequencing recommendation**: iOS submits tonight/tomorrow; Android build + closed test starts in parallel this week; Play production follows when the gate clears.
